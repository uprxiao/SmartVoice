# Windows 无麦克风模拟版原型

2026-11-02。依据用户本轮明确要求，补充专用验收版本的 S0。入口为 [windows-simulation.html](../../prototype/windows-simulation.html)，纯 HTML、CSS、JavaScript，直接打开即可。沿用已有 [Windows 视觉基准](windows-v002.md)及共享 token，不改变正式版录音胶囊的尺寸和操作。

## 页面与状态

专用版主窗明确标记“模拟测试 · 固定文字 · 不使用麦克风”。第一次快捷键进入模拟录音，第二次结束并生成固定虚构文本。页面内按钮只用于复现原型状态；正式实现继续使用全局快捷键及真实原生输入。

| 状态 | 表现 | 动作 |
|---|---|---|
| idle | 等待开始，胶囊隐藏 | 开始模拟输入 |
| recording | 原录音胶囊及模拟信号，取消和完成可用 | 再次快捷键或完成，应用内 Escape 或取消 |
| processing | 原处理胶囊，开始按钮禁用 | 等待结果，取消不得产生迟到插入 |
| inserted | 页面内固定文字插入一次并显示反馈 | 可开始下一段 |
| unverified | 保留固定结果，不自动重复 | 查看结果 |
| failed | 明确目标拒绝，保留结果 | 查看结果 |
| cancelled | 无插入，胶囊隐藏 | 开始下一段 |

所有数据均为虚构。原型的输入框属于当前页面，原型不调用麦克风、剪贴板或原生输入，不证明系统行为通过。按钮悬停、焦点、禁用和状态反馈沿用共享样式。

## 视觉对照与范围

主窗沿用 Windows 标题栏、灰白背景、字号、间距、圆角和阴影。胶囊复用共享 hud-preview 样式和波形外观，模拟信号与正式录音区分。计时沿用正式首页位置，只表示模拟会话时长。模拟标记提供用户可辨认的版本身份，不把模拟信号写成真实麦克风状态。

已用本地 Chrome 实际复核默认、模拟开始、结束固定文本、应用内 Escape 取消和无法核验场景，并观察共享胶囊及主窗视觉。检查只涉及页面内虚构输入，不能作为 Windows 原生行为通过。用户明确确认双快捷键与固定文字行为，不新增 Windows 全局 Escape，不追加 Windows 自动修改学习。
