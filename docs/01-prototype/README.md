## 打开与操作

直接双击 [prototype/index.html](../../prototype/index.html)，无需构建、安装依赖或网络。全部数据为虚构示例，只保存在本次页面内存；刷新或顶部“重置演示”恢复初始状态。

顶部评审栏在产品窗口之外，可切换首次使用/桌面端/管理后台，或选择当前页面的演示状态。它只用于评审，不进入正式产品。登录输入任意格式有效的虚构邮箱及 8–128 字符演示密码；不校验真实凭据、不发送请求。异常状态可以通过状态选择器重现。

## 数据与验证边界

- 首页/历史/使用统计采用 F-STAT-1 同口径：3 会话、13 字、30 秒成功口述、35 秒接收音频、26 字/分钟、处理成功率 100%、插入率 50%。模型页是独立 F-USAGE 样例，不与这 3 个会话混算。
- 初始词库为 8 个虚构技术词；CSV 内置 Kubernetes/React/Example Tool 等 5 行，预期导入 2、跳过 1、冲突 1、无效 1。正式测试的 F-CSV 使用另一独立初始库，不能混用。
- 所有写入、权限、录音、模型、复制与登录均为内存交互演示；不访问系统剪贴板、麦克风、目标应用、数据库或网络。固定“剩余 09:42”是截图状态，不是真实 TTL 计时器。
- 保留期限改变仅演示确认与状态，不模拟后台定时清理；真实正文读取屏障/备份恢复由 S4/S5 验证。
- 搜索/重名示例用 NFKC+小写，完整 Unicode casefold、5000 词事务容量与跨账号权限在服务端落实。只读设备列表、语言切换与主偏好英文布局已展示，完整 zh-CN/en 文案由正式 UI 资源提供并按 TC-SET-02 验证。
- 路由可直达是评审便利，不是登录/角色保护实现。真实权限、主进程 token、HTTP/WS、性能与跨平台插入必须单独验收。

本轮新增容量页面后共14路由/90场景。容量示例运行上限20、活动8、部署允许100，用于展示后续服务器高于20的配置交互；这不是本机配置或实测报告。默认开发配置的部署上限为20，扩容需按技术方案准备资源。
