# 快速纠正学习：需求变更（S1，2026-10-28）

状态：**S1 变更已起草，待本人评审**（2026-10-28 本人已确认第 4 节三项）。依据：设计讨论稿第三版补充（内部记录，未公开）、B 路线可行性实验（内部记录，未公开）、本人 2026-10-28 决定“先验证 B……按 AGENTS.md 流程往下走，开发前停下”。本文生效后修订 [BR-08](business-rules.md#br-08-修改学习) 与 PRD FR-06；技术细节在 S2，验收在 S3。

## 1. 要解决的问题

用户纠正识别文字后正常发送（例如约 6 秒内改完回车），首页学习数不增加。原因分三类，本次分别处理：

1. 插入为“未核验”时根本不观察（输入框读不到），见 LR-07。
2. 现行规则要求修改后静止 15 秒，且输入法状态未知时一律不学；发送清空输入框后丢弃已采到的修改，见 LR-02～LR-04。
3. 马上开始下一句时会取消已经发出的学习提交，见 LR-05。

## 2. 实验支持的事实（摘要）

- 只有辅助功能授权时，独立应用身份即可收到全局按键事件（只取时间和类别），未出现额外授权请求（本机 macOS 26.6.1；待本人确认只开了辅助功能）。
- 规则 B 在有效样本中：静止后回车 5/5 取到最终稿；“停在 Reac、补 t 后 0–100 ms 内回车”9/9 未把 Reac 当最终稿。
- Electron 应用默认取不到焦点输入框，需应用主动开启其辅助功能（约 1.2 秒生效）；Chromium/Electron 读不到输入法组字状态；Electron 重建输入框时没有销毁通知。

## 3. 规则

| 编号 | 规则 |
|---|---|
| LR-01 观察资格不变 | 仍只观察本机已核验（inserted 且 observable）的本次插入片段，且学习开关开启；未核验不学习，服务端准入不放宽。 |
| LR-02 结束即判定 | 观察期间出现“发送/结束编辑”信号——回车或换行键、输入框被清空、输入控件失效（读取报失效）或焦点离开——立即判定一次是否学习，不再要求静止 15 秒。没有这些信号时，保留“片段静止 15 秒”空闲判定；整体观察仍以插入确认后 60 秒为上限。每次插入最多提交一次学习。 |
| LR-03 最终稿资格（宁漏不错） | 只有满足以下全部条件的读取结果才能作为“最终修改”：①读取开始前，距上一次按键按下已安静至少 M 毫秒；②从该次读取开始到触发判定的按键（如发送回车）之间，没有任何其他按键按下；③读到的片段外围仍与插入时一致，修改仍只在本次片段内。不满足就跳过本次学习。M 在 S2 按实测确定（实验采用 150 ms）。这意味着“补最后一个字后极快发送”可能不学习，属于有意的取舍。 |
| LR-04 输入法 | 明确处于组字状态的读取不能作为最终修改。系统无法告知组字状态（Chromium/Electron 常见）时，不再一律放弃，改为必须同时满足 LR-03 的按键顺序条件（选词的空格、数字和上屏回车都算按键）。替代原“unknown 不当作已提交”的一刀切规则。 |
| LR-05 按键信号的边界 | 只在每次插入后的观察窗口内监听按键，窗口结束即停止；只记录按下时间和类别（字母、回车、退格、方向、空格、修饰键），不记录具体字符或键码序列，不上传、不入库。不新增系统权限；若某系统版本要求额外权限，该路线在该版本不启用并如实提示，不引导用户另开权限。 |
| LR-06 冻结与下一句 | 满足 LR-03 的修改被“冻结”后，即使立刻开始下一段口述也继续提交，不再被取消；新口述只停止旧观察。冻结任务有自身的有限期限，等待原插入回执确认后才提交，复用原回执，不重复插入。账号切换、退出登录、关闭学习时取消尚未提交的冻结任务。下一段口述替换旧片段的文字不会计入旧学习。 |
| LR-07 Electron 与 Chromium 系应用可读 | 当目标为 Electron 应用或 Chromium 系浏览器（Chrome 等）且读不到输入框时，产品可对该应用开启其辅助功能（Electron 官方方式及 Chromium 的增强辅助功能开关；以之后能否读到为准，不以设置返回值为准），使插入核验和学习观察可用；不需要用户新增任何权限、不弹窗；每个应用进程只开启一次，不在退出时关闭（其他辅助工具可能依赖）。开启前先记录无正文诊断信息，以便区分“读不到”的原因。该项同时影响插入核验，属本次变更范围。 |
| LR-08 页面表达 | 首页学习卡片显示最近一次观察结果：观察中、已学习（词条）、未学习·改完后立即发送无法确认最终修改、未学习·当前应用输入框无法读取、学习已关闭；不再显示暗示实时采集的“持续学习中”。不在每次口述的胶囊上提示学习情况，不加弹窗。原型见 `prototype/` 首页 learn-* 状态。历史记录逐条原因暂不做（需服务端新增字段，另行评审）。 |
| LR-10 终端 | 终端（Terminal、iTerm 等）可以粘贴，但现行严格核验通常不通过（光标位置与命令行不一致），因此不观察、不学习，首页如实显示“当前应用的输入框无法读取”。终端专用核验另行评审，不在本次范围。 |
| LR-09 不变部分 | 只学一处明确的词语替换（1–32 码点、数字/路径/否定/时间等保护规则不变）；短词组放宽本次不纳入，另行评审；分类、自动入库、提示与撤销、学习次数统计规则不变；不自动回车、不修改用户已输入的文字。 |
