## 1. 目标与范围

**本地 Qwen3-ASR 1.7B 原生流式识别，停止后官方 `deepseek-flash` 用固定 DS-R2 一次输出完整正文，关闭思考。** 沿用说话人的顺序、语气、背景和收尾，只在实际并列处整理局部列表。既有中文识别路线及用户已认可的页面不重新选型或重做。

server 接入 provider 和新正文合同；desktop 验证结果、故障、隐藏窗口、最终光标插入及学习；admin 验证模型身份、状态、调用与用量。三端均有任务，不能只交付服务端骨架。

## 2. 正文成功与失败

| 项目 | 本轮要求 |
|---|---|
| 输入 | 原始 ASR 转写和冻结词库选出的正确拼写。原转写独立保存，不用整理稿覆盖 |
| 提示身份 | 完整 DS-R2 规则及三组虚构示例，SHA256 `a1efa73302779e50d7d80396e3020470c4f0b9c522f794e64cf78ef3fee386f8`；不采用 S3，不新增模型审核/主题排版 |
| 输出 | 收齐非空、正常结束的纯正文后一次返回；保留换行、局部编号、引号、字面技术内容；不逐 token 写入输入框 |
| 忠实性 | 保留要求、动作对象、条件、否定、理由、引用、数字及明确最终改口。以原音/原话核对质量；程序不再要求模型提交逐项编辑依据，也不宣称能确定性证明全文语义正确 |
| 失败 | 空输出、断流、截断、拒绝、超时、不可达等均返回原文并标待确认；不自动插入半段或故障回退稿；保留手动重新整理 |
| 请求次数 | 正常一次 refine。沿用最多一次格式/可重试传输故障重试，共享原绝对预算，逐次记账；不另发内容修复、audit 或排版请求 |
| 预算 | 单次 LLM 最多10秒、ASR finish最多10秒、停止到结果最多30秒；不使用研究90秒观察时限 |

引用/数字/条件等仍是质量验收要求；取消旧编辑依据协议不等于这些要求已经自动通过。研究中的已知反例保留，不凭用户认可整体效果将具体失败记 pass。

## 3. 既有功能兼容

- 词库继续按用户和会话快照隔离，保留正确词/别名、上限及歧义不强改。R2 `confirmed_terms` 与旧结构化词库的转换和本机别名处理独立版本化，不伪称与研究完全同输入。
- 正文纯文本与学习分类 JSON 分用途。学习沿用已确认插入片段、中文整词、IME 提交、15秒稳定/60秒截止、自动学词/不确定跳过和撤销。没有编辑依据不代表学习免证据。
- 官方正文请求只包含原转写和已授权词表。未经新增授权，不把真实整理全文或派生学习片段发往官方分类。独立本地分类可继续；未配置可用分类时明确学习失败，不能伪称入库。
- 对外 result、历史原稿/整理稿、回执和统计合同沿用。正常插入按真正粘贴前的最新光标和选区，一次写入、不自动 Enter；无目标留历史并允许下一段。快捷键不唤起主窗口。
- 取消、换账号、退出、重复事件及旧 attempt 不得迟到写入/学习。PCM失败重试600秒与D+1秒父进程/D+2秒worker收口要求继续有效。
