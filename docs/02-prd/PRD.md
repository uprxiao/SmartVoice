# SmartVoiceInput PRD（v0.3 · 方案 B 与20路容量）

> 状态：2026-10-17 按用户授权细化；范围保持方案 B，S0 已通过；最终门禁见文档索引。
> 依据：已拍板决策 D1–D24、原型与核心行为证据。具体判定以 [业务规则](business-rules.md) 为准，本文保留 FR 编号供追踪。

## 1. 产品概述

SmartVoiceInput 是一个跨平台语音输入工具：用户按下快捷键说话，系统在服务端完成语音识别与智能整理，把可直接使用的文字插入当前光标位置。产品同时提供词库学习、历史记录和使用统计。

与参考产品的差异：

- 识别与整理可部署在公司自己的服务器，音频不出内网。
- 模型通过 provider 配置选择；V1 ASR 限本机/内网，文本整理允许内网或公网模型。
- 提供独立的账号体系与管理后台。

## 2. 目标用户

- 需要大量文字输入的产品、研发、运营人员。
- 对语音数据隐私有要求、希望私有部署的团队。

## 4. 角色与权限

| 角色 | 权限 |
|---|---|

- 所有业务数据按 `user_id` 隔离。
- 管理后台必须有独立登录与角色校验。

## 5. 核心流程

```
登录 → 客户端启动 → 焦点放入目标输入框 → 按快捷键开始录音
→ 流式上传音频 → 服务端 ASR（增量）→ 停止录音 → 尾音收尾
→ 服务端 LLM 整理 → 返回整理稿 → 客户端插入
→ 观察本次插入的局部修改 → 学习词条（可选）
```

### 5.1 状态机

```
idle → preparing → recording → finalizing → refining → ready
                                                  ├→ inserted → idle
                                                  ├→ review（待确认）
                                                  └→ error
ready 前可取消 → cancelled；ready 后关闭结果不删除历史；插入不能以取消撤回
ready/review/inserted → preparing：可直接开始下一段，不要求先复制/确认；旧结果留在历史，无光标时不插入
```

录音区提示（2026-10-20现场反馈）：准备及录音期间不在麦克风按钮下重复显示输入目标/辅助功能权限警告；侧边“插入目标”和设置中的权限说明保留。麦克风授权错误仍须明确提示并停止采集；辅助功能未授权不阻断录音及历史保存，实际插入失败仍提示并提供复制，不把隐藏重复文案视为权限已恢复。

首次麦克风授权等待不消耗服务端音频空闲预算：macOS仍在系统授权提示时保持本机准备，可取消；授权通过且实读确认后才创建语音会话。取消或换账号后的迟到决定不得开始旧录音；拒绝与无法确认分别说明检查系统权限后显式重试，不自动重试。

2026-10-20 用户要求胶囊细节对齐参考产品，依据发行产物补查（内部记录，未公开）：准备54×12、点按录音116×34、普通处理92×34（逻辑像素）。处理时隐藏波形及完成按钮，以持续 loading/示意进度等待真实结果；达到6000ms＋ceil(录音毫秒/30000)×500ms仍未返回，显示“处理耗时比平时更长…”而不确诊网络故障。结果到达后完成过渡约600ms收起，不以胶囊收起冒报已插入。处理中仍可在主窗口取消；新会话、重试、取消、失败、退出须清理旧动画和提示，不改变会话超时/迟到结果规则。

2026-10-26真人ASR质量：用户接受整体原意基本保留时少量词语、关键词或专名听错，不做本轮特殊纠错；“大概90%”是主观接受范围，不是测得准确率。见[明确决定](asr-quality-decision-20261026.md)。该容错用于语音识别质量，不改下文R2对既有转写的整理忠实性、协议、插入及性能要求。

| 可用性 | 断网/超时可恢复；迟到的结果不得写入新目标 |
| 可观测 | 记录阶段耗时、排队耗时、错误/回退、模型用量与有界资源使用；后台无用户正文 |
| 容量 | 20路真实负载与同步停止下保持上述时延目标；20路未实测，不能以空闲连接或大量原文回退替代。后台可调，算力/队列/内存独立受限；详见并发设计与F-CAPACITY |

## 8. 统计口径

以 [BR-10](business-rules.md#br-10-统计与保留) 为唯一公式来源：中文/英文均按 Unicode 字母或数字码点计数，不混用英文词数；自然日固定 Asia/Shanghai；录音次数、处理成功率、插入成功率、模型调用次数分别计数。重试不增加录音次数，历史正文清理不清除累计统计。

## 9. 验收标准（高层）

- 新用户可注册、登录、完成一次完整口述并插入。
- 词库修改在后续识别中生效，能按有效别名纠正为正确词；允许同句多处纠正，不要求区分专名与普通词义。无映射词、歧义别名和数字/路径/否定等仍按 BR-08/09 保护。
- 断网、取消、超时、插入失败均有明确反馈且不重复插入。
- 管理后台可查看用户与使用统计。
- 全部测试用例与执行前置见 `docs/04-test/`；文档检查不能代替真实模型/音频/控件验收。
