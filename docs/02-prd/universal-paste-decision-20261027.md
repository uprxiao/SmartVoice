## 产品规则

- macOS 普通听写统一采用一次 PID 定向 Command-V，由目标应用处理实际光标、选区与富文本结构。无需应用正向名单，不先做 AX 文本写入，也不在失败/不确定后换另一条路线再写一次。
- 当前前台进程/生命周期与可复核的标准窗口仍是派发边界。系统 AX 焦点应用缺值时，允许使用有界主线程 run-loop 刷新后的 AppKit 前台信息；不是复用录音开始或上一条结果的应用。无法确认前台进程/窗口或权限不足时零写入并保留结果。
- 焦点控件、原文或选区缺失不单独阻止粘贴。能够读取的明确密码/保护/禁用/只读状态及已知菜单/工具栏/按钮等非输入状态仍拒绝，不读取密码值。辅助功能属性不支持不当作已确认只读。
- 控件完全不可读时无法保证识别未知密码/只读属性，也无法判断同窗口的真实输入焦点；本轮已向用户说明此限制，用户仍明确选择通用粘贴机制。只可报告一次尝试，不能声称所有目标必定插入成功。
- 正常自动插入以资格确认和本机一次执行登记后的最新前台位置为准。手动/历史插入仍显式指定，不能激活不可核验的旧目标；可读目标的显式恢复仍需快照校验。
- 可读快照只用于严格核验及有限学习：前后文、结果与光标均相符才 inserted/observable=true。不可读、选区异常、读回失败或结果不确定为 unverified/unknown/observable=false，不学习、不自动重试。不得为了让 AX 预期成立而改写整框或事后移动光标。
- 保存全部可物化剪贴板类型，派发前确认本轮仍拥有剪贴板；完成后仅在版本仍属本轮时恢复，保留用户新复制内容。不 Enter/发送。服务端 claim、本机 journal 和同结果不重复规则保持。
