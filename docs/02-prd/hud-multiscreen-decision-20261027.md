# 多屏录音胶囊定位决定

本人使用三个屏幕，明确要求“选中的位置在哪个屏，录音胶囊就应该出现在哪个屏”。优先使用当前输入插入点/选区的屏幕；读不到插入点时用当前焦点控件，再用前台窗口，仍无法读取时按鼠标屏兜底。录音/处理中允许切换输入屏，胶囊跟随当前目标屏；保持不抢焦点、不自动弹主窗。使用显示器workArea全局坐标居中靠底，保留负坐标和Dock/菜单栏留白。

静态核对当前参考产品是100ms轮询鼠标屏；本产品输入位置优先是本人明确需求的独立方案，不称照抄参考产品焦点逻辑。第三方只参考机制，不复制私有实现。未完成本机三屏实际观察前不宣称通过。

原生只返回位置/尺寸/来源，不读取或记录输入框正文、密码、窗口标题；不捕获/绑定插入目标，不改变插入权限和时机。位置读不到不阻止录音/插入；节点查询限时，胶囊隐藏/新会话后过时返回不得再显示或移动。初次几何探测最多等待150ms，再鼠标屏兜底，避免固定主屏闪现；显示期间250ms复核，屏幕/工作区改变时重新定位。
