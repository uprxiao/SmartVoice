# Windows 临时模拟验收版

2026-11-02，S1 补充。用户明确要求在没有音频输入的 Windows 台式机验证产品插入及其他桌面功能，并确认这是验证结束后移除的临时逻辑。需求评审依据是本轮确认的双快捷键、固定文本、尽量复用产品逻辑和可移除范围。[S0 原型](../01-prototype/windows-simulation.md)沿用现有视觉基准。

## 行为与边界

| 编号 | 要求 |
|---|---|
| SIM-01 | 交付独立 Windows x64 模拟测试安装包，主窗、登录页和必要状态明确显示模拟标识，用户只需安装产品，无需安装开发运行库 |
| SIM-02 | 第一次使用实际全局快捷键显示原有非激活胶囊并开始模拟会话；再次快捷键结束，产生固定文字“这是一段 Windows 模拟输入测试。React、Docker 和 TypeScript。” |
| SIM-03 | 模拟路径不请求、读取或采集麦克风，不创建 AudioContext、AudioWorklet 或真实音频设备；权限区说明本版无需麦克风，不伪报系统已授权 |
| SIM-04 | 正式客户端的 HTTP/WS、会话身份、ACK、结果资格、claim、持久执行日志、一次原生输入及回执提交复用同一实现；临时结果由独立本机测试设施提供，不另写原生插入状态机 |
| SIM-05 | 使用实际粘贴前的最新前台输入位置或选区。记事本、Chrome 和微信等走通用 Ctrl+V，不抢焦点、不自动回车或发送；保护控件与高权限窗口沿用拒绝规则，可读回时严格核验，否则 unverified，结果保留且不自动重试 |
| SIM-06 | 胶囊取消、原有应用内 Escape、退出、账号切换、Renderer 中断及系统休眠沿用正式生命周期约束。外部软件的 Escape 仍由外部软件处理，不新增全局 Escape |
| SIM-07 | 历史、词库、设置、快捷键持久化、托盘、单实例、自启与凭据恢复保留正式桌面页面和本机实现。模拟设施保存独立虚构账号与数据，不读取或修改正式账号、用户词库、音频或服务器全局 provider |
| SIM-08 | 模拟版有独立产品标识、安装目录、用户目录、单实例域、自启和卸载项。与正常版并存时不得改写正常版状态；快捷键冲突据实际结果反馈 |
| SIM-09 | 测试模式仅由专用构建入口选择。正常安装包不能通过运行参数、环境变量或 Renderer RPC 开启模拟功能；正常构建不包含模拟 host/合成源，模拟构建不包含真实采集模块 |
| SIM-10 | 模拟结果不能计入真实采集、ASR/LLM 质量、正式后端鉴权、PostgreSQL、Admin 或完整 S5 验收。物理键盘、IME、多屏、系统重新登录和实际微信兼容性仍逐参数记录 |
| SIM-11 | 模拟包仅作为本版验收 artifact，不创建应用版本 tag 或公开 Release，不覆盖已交付正常安装包 |
| SIM-12 | 临时实现集中在独立产品装配、模拟模块、构建和验证入口。用户确认本轮验证完成后按移除清单删除临时部分，恢复正常装配；正式插入、防重和系统行为保留。移除前后均验证正常包不含模拟能力 |

Windows 自动修改学习继续按 WIN-12 后移，本批不扩围。模拟后端只是本机验收设施，其虚构账号与统计不代表服务端生产能力通过。
