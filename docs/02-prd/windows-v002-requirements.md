# Windows v0.0.2 需求补充

2026-10-29。S1 正式条款。需求评审依据为本人已确认的[范围、平台差异及 Q1–Q7](windows-version-decision-20261029.md)，本次逐项纳入正式 PRD 并完成一致性复核，没有追加 Windows 修改观察。界面见 [S0 补充原型](../01-prototype/windows-v002.md)。阶段 1 技术门禁已通过；继续 S2，尚未进入 S4。

以下 WIN 编号是既有 FR 的平台约束，用于本版追踪，不替代通用 PRD/业务规则及既有验收标准。需求文档版本、试验批次与应用版本 `v0.0.2` 分开计数。

## 范围与角色

交付 Windows 10/11 x64 的录音、处理、普通窗口通用插入、平台权限反馈及后台运行；保留原有账号、服务配置、词库、历史和管理后台。Windows ARM、Linux 桌面、提权运行、uiAccess、代码签名、跨进程输入法组合态探测和 v0.0.3 快速纠正学习均不在本版范围。

普通用户仍只访问自己的账号数据；管理员仍使用原后台角色校验。本机权限、自启和托盘不新增服务端管理权限；自启是本机设置，不同步成账号全设备开关。未登录不允许开始口述；托盘可打开登录页或退出。

## 逐项需求

| 编号 / 通用归属 | 行为与验收约束 |
|---|---|
| WIN-01 / FR-04-01～04 | 正常听写在资格确认、本机一次执行登记之后，以实际粘贴前的当前前台输入位置为准。录音/等待/结果到粘贴前可切换应用、光标或选区；一次 Ctrl+V，由目标处理当前选区，保留选区外文字；不因较早目标不同拒绝，不恢复旧窗口，不自动 Enter/发送，不自动重复 |
| WIN-02 / FR-04-02、05 | 可读时以准确原前缀+本次文字+原后缀、光标与零残余选区严格读回判定 `inserted`。记事本与 Chrome 普通 input/textarea 的光标插入和选区替换均必须成功，包含中文、emoji、换行（单行框使用适用文本）。不可读可尝试一次，结果固定 `unverified`；不以 SendInput 返回成功或仅正文包含文字代替读回 |
| WIN-03 / FR-04-03、05 | 实际目标必须是当前可确认的可见应用窗口，生命周期可复核，处于交互桌面，完整性级别不高于本应用。已知密码/保护/只读/禁用/明确非输入状态拒绝；高权限目标不尝试粘贴、不自动写剪贴板，明确说明并保留结果，由用户点复制。未知控件的安全属性不能保证全部识别，此限制须在帮助/兼容说明中保留 |
| WIN-04 / FR-04-02～04 | 粘贴前处理快捷键修饰键残留，目标仅收到普通 Ctrl+V。保存原剪贴板，写入结果时带历史/云同步排除格式；仅本轮版本未被改动才恢复，用户中途新复制的内容不得被覆盖。不能安全保存的格式或内容应在改变剪贴板前拒绝自动插入并说明；用户主动复制属于显式操作 |
| WIN-05 / FR-02-01、07 | Windows 显示实际麦克风状态与“打开麦克风隐私设置”；不使用 macOS 的系统授权弹窗。已被禁用时停止本次启动并说明桌面应用总开关、改动后可能需重启。未知/检查失败不能伪报已允许；检查中可取消，取消/账号切换后的迟到结果不得启动旧录音。实际采集失败须明确反馈并取消本轮，不伪造录音波形或上传成功 |
| WIN-06 / FR-04-03、FR-09-02～03 | Windows 设置、首次使用、帮助、HUD 和结果文案不出现 macOS 辅助功能授权路径；权限区改为麦克风与输入能力说明。明确零写入失败的 HUD 沿用复制/关闭、8 秒收起及新录音立即让位；管理员目标不出现“去授权”。不可核验不冒充失败后可安全重试，不弹已输入提示；完整原因与结果仍可在主窗口/历史查看。全部新增文案有简中/英文资源 |
| WIN-07 / FR-09-03、BR-11 | Windows 关闭主窗口时隐藏到托盘，保留录音 Renderer，应用继续运行；首次关闭仅一次提示。托盘菜单只有“打开/退出”；打开及再次启动 exe 均调出现有主窗口，意外销毁时重建，不产生第二实例。明确退出释放快捷键、录音、原生进程和窗口；退出/切换账号的旧结果不得迟到写入 |
| WIN-08 / FR-09-03 | Windows 设置提供开机自启，默认关闭。开启后启动 Windows 时进托盘，不弹主窗口；系统“启动应用”可独立禁用，页面区分应用配置与系统生效状态并给出入口。保存中禁重复；真实保存与读回成功后才显示生效，失败保留原值。macOS 不新增自启设置 |
| WIN-09 / FR-09-01 | Windows 保留表拒绝 Shift+Space、Control+Space 及其等价写法；保留原有 Escape/系统组合等规则。Ctrl+Shift+Space 为真机实测前候选，V-13 同时验证 Ctrl+Alt+Space，按已决 Q2 选择兼容默认值。注册/保存失败保留原快捷键；成功不表示能检测所有第三方自定义占用 |
| WIN-10 / FR-02-02、FR-04-01 | 胶囊显示/更新/隐藏不抢前台、不弹主窗口；录音及处理时优先跟随当前输入位置所在屏，再按控件/窗口/鼠标回退，落在该屏 workArea。保留负坐标和不同缩放的全局坐标语义；隐藏/取消后不得被迟到定位结果复活 |
| WIN-11 / FR-04-05、非功能兼容 | 以 Rust 独立原生辅助程序随安装包交付，真实服务/模型/音频/基线输入闭环必须用 Windows 安装包验收。支持 Win10/11 x64；实际取得的桌面版本按 Q6 验收，另一个版本如实写未单独验收。v0.0.2 未签名，说明可信下载来源和 SmartScreen“更多信息→仍要运行”；托管 Windows Server 不能替代桌面真机。Mac 原有路径须回归 |
| WIN-12 / FR-06、范围边界 | 按已确认范围，本版 Windows 只做插入与严格读回，不实现输入后修改观察；自动纠正学习留后续，界面明确说明本平台暂不支持，仍可手动管理词库并在后续识别中使用已有词条。不改变其他设备的账号学习偏好或 Mac 已有学习，不新增快速学习事件通道。`release` 是既有目标句柄释放所必需，须保留，不属于学习范围扩展；是否追加旧版 Windows 学习可由本人另行扩围，当前未追加 |

## 状态与文案

| 情形 | 用户可见结果 | 操作与副作用 |
|---|---|---|
| 管理员窗口 | “目标窗口以管理员运行，无法自动输入。请复制结果后手动粘贴。” | 自动路径零写入；复制须点击，关闭保留历史 |
| 受保护输入框 | “当前输入框受保护、只读或已禁用，结果已保留。” | 不读取已知密码正文、不粘贴；复制/关闭 |
| 最终目标不可确认或显式目标失效 | “本次没有输入，结果已保留。”及具体原因 | 正常路径不退回旧位置；显式目标失效后可重新指定或复制 |
| 写入可能已发生但无法读回 | “无法确认是否已输入，请先检查目标。不会自动重试。” | `unverified`，不分配成可自动重试的零写入失败；可主动复制 |
| 麦克风禁用/未知 | 分别显示被系统禁用/尚未确认，不能合并成已允许 | 系统隐私设置、重新检查、取消准备；错误可恢复 |
| 自启被 Windows 禁用 | “系统已禁用启动”，保留应用开启偏好并说明系统开关 | 打开启动应用设置；不谎报自启正在生效 |
| 关闭主窗口 | 首次提示“SmartVoiceInput 仍在后台运行，可从托盘图标打开或退出” | 继续运行，不等于退出；后续关闭不重复首次提示 |

HUD 使用短文案，详细解释放主结果或帮助；不增加超出既有尺寸的长卡片。成功只基于读回或系统实际保存结果；原型反馈不能作为真实效果证据。

## 三端与验收边界

Desktop 实现 Windows 差异与本机设置；Server 保持现有 claim/receipt、租户、结果保留、词库与统计契约；Admin 按真实回执显示统计与用量。S4 三端均有责任和回归任务，不以本地 helper 或服务骨架作为完整交付。

阶段 1 的阻断通过只证明技术可行。物理键盘按住/提前释放、真实输入法、Win+V 历史与格式保真、终端多行确认、真实麦克风、多屏 DPI、自启/托盘和 Windows 安装包等均须按后续 S3 正式用例与 S5 清单留证。未执行不记通过，用户未明确发版前只推送开发分支，不创建版本标签或发布。
