## 14. 验收门禁

1. 全部必需功能、协议、安全、隐私用例通过；故障注入用例按其定义的失败恢复行为判通过，不是接口永远成功。
2. 基线控件在声明平台自动插入并读回成功；扩展矩阵逐项列自动支持/复制降级/未验证。Windows真实验收缺失时不能宣称跨平台完成。
3. TC-NFR-01固定环境指标通过；原目标不能由开发自行降低。环境、音频或性能结论待定时保持blocked并列出缺项。
4. 内容保留、词库/历史/统计、真实模型、音频、跨应用插入完整闭环均须有证据。已知限制不能掩盖基线失败。
5. 文档覆盖检查只证明用例已定义；不代表S3评审自动通过，更不代表S4/S5完成。最终阶段登记见主文档索引。
