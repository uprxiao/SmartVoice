第一段，准备一次周末活动。

今天我们安排一次虚构的周末活动。参加的人有小林、小周和小陈，一共三个人。大家准备星期六上午九点，在社区图书馆门口集合。出发前，每个人都要检查水杯、雨伞和手机电量。小林负责带一张纸质地图，小周负责准备简单的午餐，小陈负责确认当天的天气。我们不会因为一时赶路就临时改变集合地点。如果有人晚到，其他人先在图书馆里面等，不要站在路口。到了九点十五分，大家再一起决定是否出发。活动的目的，是慢慢参观城市里的公共空间，记录沿途看到的小变化。比如新种的树、修好的长椅，还有增加的无障碍坡道。我们只描述能够直接观察到的事情，不把自己的猜测写成已经发生的事实。出发前，还要把计划再读一遍，确认每个人都知道下一站在哪里。

第二段，参观社区图书馆。

我们先走进图书馆的一层大厅。左边是归还图书的机器，右边是供读者休息的区域。服务台旁边有一块通知牌，写着儿童阅读活动将在下午两点开始。小林想找一本介绍植物的书，小周更喜欢城市建筑，小陈准备看看旅行随笔。三个人约定，先各自寻找感兴趣的内容，四十分钟以后再回到大厅集合。看书的时候，我们把手机调成静音，说话也尽量放轻声音。如果找不到书架，就请工作人员指一下方向，不随便移动别人的物品。我们还注意到，靠窗的桌子上放着几盏阅读灯，其中一张桌子的高度可以调整。这个设计对不同身高的读者都比较方便。离开以前，大家把借阅规则看清楚，确认哪些书可以带走，哪些资料需要留在馆内阅读。整个过程不用着急，重要的是把事情做完整。

第三段，商量午餐和采购。

离开图书馆以后，我们到附近的小市场买午餐材料。原来的预算是一百二十元，后来决定留下二十元作为备用。小周先买面包和水果，小林挑选蔬菜，小陈负责记录价格。大家特别说明，不购买含有花生的点心，也不买需要长时间冷藏的食物。买东西之前先看保质期，再看包装有没有破损。如果同一种商品有两个规格，我们会比较实际数量，不只看标签上的大字。到了结账的时候，小陈重新核对清单，发现少买了一瓶饮用水，于是请其他人等一下，自己回到货架补上。结账完成后，我们把收据放进一个小信封，等活动结束再计算每个人分摊的费用。这里的数字都是虚构的，只是为了验证连续讲话里面的金额、数量和前后顺序能不能被保留下来。

第四段，讨论一个虚构的软件任务。

午饭以后，大家坐下来讨论一个小型软件项目。今天的任务，是 review 一下 API 的 timeout 设置，同时保留错误日志，不修改数据库。小林认为，应该先确认问题出现的条件，再比较修改前后的结果。小周提醒大家，不要一次调整太多参数，否则就很难知道是哪一个变化起了作用。小陈建议，先准备一组固定的测试数据，再把运行时间和失败次数分别记录下来。如果某一轮没有完成，就如实写明原因，不把它算成成功。如果整理出来的文字与原话不一致，也要区分是识别阶段听错了，还是整理阶段改变了意思。我们希望输出能去掉多余的口头停顿，但原来的限制条件仍然要保留。例如只保存日志、不发送消息，以及不自动按回车执行。这几个要求可以换一种说法，但是不能变成相反的意思。

第五段，安排下周的学习计划。

接下来，我们商量下周的学习安排。星期一整理阅读笔记，星期二学习一个新的工具，星期三复习之前遇到的问题。星期四留给实际练习，星期五做一次简短回顾。每次学习先用十分钟明确目标，再用二十分钟动手操作，最后留五分钟记录结果。遇到暂时不懂的地方，先写下具体的问题，不急着给自己下结论。如果发现计划太满，就减少当天的任务数量，保证最重要的事情能够做完。小林想学习怎样把资料分门别类，小周想练习写清楚操作步骤，小陈希望改善文件的命名方式。大家都同意，文件名应该能看出内容和版本，而不是连续写好几个最终版。旧的记录也要保留，因为它们能够说明一个想法是怎样逐步改变的。下一次讨论的时候，我们再根据实际结果调整安排，不凭印象判断有没有进步。

第六段，回顾活动和检查结果。

傍晚的时候，我们回到最初集合的地方。大家先确认个人物品没有落下，再检查公共区域是否收拾干净。小林把纸质地图折好，小周把剩余食物装进袋子，小陈负责汇总今天的开支。我们回顾了图书馆的阅读空间、午餐采购的过程，还有下午讨论的软件任务和学习计划。每一部分都有不同的内容，不应该因为录音时间比较长，就漏掉中间完整的一段。现在这段话仍然属于连续朗读测试，我们继续按照正常语速讲话，不故意加快，也不刻意拖长。等应用达到六分钟的时候，让它自己结束录音。结果出来以后，再检查前后顺序、否定条件、金额和时间是否大体一致。如果发现问题，就记下它发生在第几段，保留当时的实际结果，再讨论后续怎样处理。今天的虚构活动到这里已经接近尾声，大家准备分别回家。

备用段，如果录音还没有自动结束，就继续往下读。

回家的路上，小林又想到一个可以改善的小细节。下次组织活动，可以提前准备一张简短的任务卡，把集合地点、预计时间和负责的人写清楚。任务卡不需要很长，但要让第一次参加的人也能看懂。小周补充说，还可以准备一个空白栏目，专门记录临时变化。例如天气突然转冷，或者原定的场馆临时关闭，都应该在记录中说明。小陈认为，活动结束以后也可以收集一两条具体建议，而不是只问大家高不高兴。有人可能喜欢安静的阅读时间，有人可能更喜欢户外散步，不同的偏好都可以保留下来。以后再安排新活动的时候，就有了可以参考的依据。我们现在继续自然地朗读，直到录音胶囊自动进入处理状态，再停止说话。
