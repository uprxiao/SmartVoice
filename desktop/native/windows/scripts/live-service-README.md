# Windows 客户端真实服务联调夹具

`product-live-service.ps1` 在一次性 CI、Medium 用户下运行真实开发 Main/preload/Renderer，通过实际 DOM 输入连接独立 PostgreSQL/FastAPI，再用实际 Admin 构建核对同一数据库。所有账号使用 `example.test`；密码和签名密钥随机生成，只放私有文件，禁止上传。

执行前冻结源码摘要与10个参数：实际服务地址/Windows能力、错误密码、真实注册自动登录、首次麦克风权限引导及Windows界面、系统拒绝麦克风时不创建录音会话、加密凭据跨进程恢复、桌面退出、普通用户拒绝管理权限、后台2账号/0会话/0插入、后台退出。保存账号后以后台参数启动，另核0可见窗口/不抢前台/不弹权限引导，第二实例才打开原窗口。数据库另核 Argon2、账号学习偏好保留、最终0活动登录。

服务端仍只承诺既有 Linux/macOS 部署。此处 Windows PostgreSQL/Python 仅为隔离测试设施：使用预装 `PGBIN` 新建集群，必要时读取 PostgreSQL 的真实 TZif，不启动系统服务。端口已被占用、目录已有内容或所有权不符均拒绝执行；控制器保留自己创建的进程对象并核验 API 监听 PID。

`initdb` 会限制自身令牌，不能依赖仅 Administrators 可访问的父目录。`fixture-acl.ps1` 只在已核对所有权、尚无集群的本次 `RUNNER_TEMP` 目录，为当前用户 SID 补充可继承访问并独立读回；报告仅含调整前后布尔值，不记录身份。不会修改系统 PostgreSQL 服务、部署数据库或其他目录。

安装包先按分发配置独立构建/安装验证，随后才构建使用既定 `127.0.0.1:17863` 的开发版本。开发产物不回装到 NSIS 中，安装器只有全部自动门禁通过后才保留。真实麦克风状态为 denied 时只验拒绝流程，不覆盖权限、音频或模型返回值，不能称真实录音/模型/正式安装包端到端通过。

失败和 acquired 数据保留；退出只停止本次服务、客户端、浏览器和独立集群，并撤销夹具残余登录。上传仅允许明确列出的匿名报告，`credentials.private.json`、配置、用户目录、PG数据及私有日志均排除。真机、IME、物理按键、系统重登录、真实音频/模型与 S5 要求保留。
