# Windows 客户端真实服务联调夹具

`product-live-service.ps1` 在一次性 CI、Medium 用户下运行真实开发 Main/preload/Renderer，通过实际 DOM 输入连接独立 PostgreSQL/FastAPI，再用实际 Admin 构建核对同一数据库。所有账号使用 `example.test`；密码和签名密钥随机生成，只放私有文件，禁止上传。

执行前冻结源码摘要与10个参数：实际服务地址/Windows能力、错误密码、真实注册自动登录、首次麦克风权限引导及Windows界面、系统拒绝麦克风时不创建录音会话、加密凭据跨进程恢复、桌面退出、普通用户拒绝管理权限、后台2账号/0会话/0插入、后台退出。保存账号后以后台参数启动，另核0可见窗口/不抢前台/不弹权限引导，第二实例才打开原窗口。数据库另核 Argon2、账号学习偏好保留、最终0活动登录。

服务端仍只承诺既有 Linux/macOS 部署。此处 Windows PostgreSQL/Python 仅为隔离测试设施：使用预装 `PGBIN` 新建集群，必要时读取 PostgreSQL 的真实 TZif，不启动系统服务。端口已被占用、目录已有内容或所有权不符均拒绝执行；控制器保留自己创建的进程对象并核验 API 监听 PID。

`initdb` 会限制自身令牌，不能依赖仅 Administrators 可访问的父目录。`fixture-acl.ps1` 只在已核对所有权、尚无集群的本次 `RUNNER_TEMP` 目录，为当前用户 SID 补充可继承访问并独立读回；报告仅含调整前后布尔值，不记录身份。不会修改系统 PostgreSQL 服务、部署数据库或其他目录。

监听端口必须属于本次启动的 Python 进程，或 Windows venv 重定向器直接创建的实际解释器子进程；运行时自报 PID/父 PID、OS 进程父子关系/创建时间、实际进程映像摘要和端口拥有者须全部一致。只出现 PID 文件或端口可访问不算所有权证明。

正式 L2、开发 Main 和 NSIS 使用同一 `x86_64-pc-windows-msvc`、`+crt-static` 构建的 helper，执行前核三处二进制 SHA-256 一致。技术 probe/verify 仍独立；默认动态 CRT 构建不能冒充最终打包 helper，构建参数不同的文件摘要也不能直接互作相同产物。

保存账号恢复失败时，先保留只读 DOM 与 profile 元数据（密文头类型/大小/摘要、Local State 的键存在布尔、设备文件摘要），不上传密文、加密密钥或凭据。独立 `credential-control.cjs` 只对虚构 canary 做真实 safeStorage 的同步强制退出、同步正常退出、同版本异步 API 强制退出、公开 DOMStorage flush 后强退、独立正常退出预热后强退五组对照；异步 API 仅作候选实验，不能代替产品恢复通过。仍继续独立 Admin 用例；残余桌面登录只在最后清理，不能冒称产品注销成功，整轮恢复门禁保持失败。

`-HistoryInsert` 追加5组可以独立执行的实际界面用例。原保存账号恢复即使失败，也先保留原失败/阻断并显式撤销本次夹具残余登录，再以新的实际登录进行历史验证；这次准备清理不算产品注销。通过独立登录、真实 HTTP/WS 和4帧零 PCM 准备一个 Mock 历史结果，再明确以测试数据准备设置该条 `review_required`；这不代表真实质量守卫或麦克风通过。实际客户端点击历史重新整理、未指定目标时拒绝、3秒选择已拥有的 Notepad、从客户端前台恢复原选区并插入、重复点击及退出；技术 probe 只做 OS 焦点/选区准备和独立全文/光标读回，业务使用正式 Main/RPC/helper。独立 SQL 要求同一会话两版结果、恰一条 inserted/observable 回执、账号全局学习偏好不变且零学习事件；实际 Admin 必须显示1会话/1插入/14字，并退出。任一原用例失败仍令整轮失败且不保留安装器，独立历史通过不降低账号恢复门禁。

安装包先按分发配置独立构建/安装验证，随后才构建使用既定 `127.0.0.1:17863` 的开发版本。开发产物不回装到 NSIS 中，安装器只有全部自动门禁通过后才保留。真实麦克风状态为 denied 时只验拒绝流程，不覆盖权限、音频或模型返回值，不能称真实录音/模型/正式安装包端到端通过。

失败和 acquired 数据保留；退出只停止本次服务、客户端、浏览器和独立集群，并撤销夹具残余登录。上传仅允许明确列出的匿名报告，`credentials.private.json`、配置、用户目录、PG数据及私有日志均排除。真机、IME、物理按键、系统重登录、真实音频/模型与 S5 要求保留。

各实际界面用例另尝试保存 `screenshots/<用例ID>.png`，由已核验的客户端页面生成，供 Artifacts 下载查看；不代表 Windows 桌面直播或原生对话框全景。截图前检查可见文字与非密码输入框未泄漏夹具密码或 token；截图不可用单独登记。图片只作辅助，全文/光标/事件/数据库等独立断言仍决定 pass/fail，不以截图替代真实结果。
